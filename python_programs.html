Question: Write a Python program to find the factorial of a number.
Solution: 
num = int(input("Enter a number: "))

fact = 1

for i in range(1, num + 1):
    fact = fact * i

print("Factorial =", fact)
Output:
Enter a number: 5 Factorial = 120
Question: Write a Python program to check whether a number is prime or not.
Solution: 
num = int(input("Enter a number: "))

if num < 2:
    print("Not Prime")
else:
    for i in range(2, num):
        if num % i == 0:
            print("Not Prime")
            break
    else:
        print("Prime Number")
Output:
Enter a number: 17 Prime Number
Question: Write a Python program to reverse a given number.
Solution: 
num = int(input("Enter a number: "))

reverse = 0

while num > 0:
    digit = num % 10
    reverse = reverse * 10 + digit
    num = num // 10

print("Reverse =", reverse)
Output:
Enter a number: 12345 Reverse = 54321
Question: Write a Python program to find the sum of first N natural numbers.
Solution: 
n = int(input("Enter N: "))

sum = 0

for i in range(1, n + 1):
    sum = sum + i

print("Sum =", sum)
Output:
Enter N: 10 Sum = 55
Question: Write a Python program to print the multiplication table of a number.
Solution: 
num = int(input("Enter a number: "))

for i in range(1, 11):
    print(num, "x", i, "=", num * i)
Output:
Enter a number: 5 5 x 1 = 5 5 x 2 = 10 5 x 3 = 15 5 x 4 = 20 5 x 5 = 25 5 x 6 = 30 5 x 7 = 35 5 x 8 = 40 5 x 9 = 45 5 x 10 = 50
